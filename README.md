# Folha de Pagamento Básica

Projeto desenvolvido em C# para calcular o salário de um funcionário com base nas horas trabalhadas e no valor recebido por hora.

## Sobre o projeto

O programa lê:
- Número do funcionário
- Quantidade de horas trabalhadas
- Valor recebido por hora

Depois calcula o salário total e exibe o resultado formatado com duas casas decimais.

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio

## Conceitos praticados

- Variáveis
- Entrada de dados
- Conversão de tipos
- Operações matemáticas
- Formatação de valores monetários
- Uso de `CultureInfo.InvariantCulture`

## Exemplo de entrada

```txt
25
100
5.50
```

## Exemplo de saída

```txt
Número Funcionário: 25
Salário: R$ 550,00
```

## Objetivo

Este exercício foi desenvolvido para praticar lógica de programação e manipulação de dados em C#.
